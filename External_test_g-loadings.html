External tests g-loadings comparison

3 November 2026

This page presents estimated g-loadings for several external cognitive tests for which a large enough amount of data are present in the database. Whenever available, data provided/published by other test creators is also incorporated into the table. These estimates should be considered preliminary, as the available sample sizes and test connections are still relatively limited.

A "test connection" refers to a valid correlation computed between the test in question and another test in the database.

Correlations are generally computed between raw scores on the internal tests and raw scores on the external tests. For standardized assessments, such as the WAIS, correlations are instead computed between raw scores on internal tests and standardized I.Q. scores. Based on the way the other test creators aggregate results across multiple tests under a single correlation value, it seems that they compute correlation between standardized scores.

The data come from authenticated candidates whose previous test scores are known. The number of candidates for whom such information is available is currently limited.

If you have previously taken an I.Q. test, you are encouraged to share your scores with the test author through the Score Submission Interface.

Contributions are valuable even if you have no intention of taking any test on this platform, as they help improve the statistical analyses presented here.

Clicking on a correlation coefficient provides access to the corresponding detailed report, containing either the exhaustive list of individual correlations available in the database or the report supplied by the respective test creator.

This page will be updated regularly as additional data become available.
