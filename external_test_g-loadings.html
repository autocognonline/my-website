External tests g-loadings comparison

13 November 2026

This page presents estimated g-loadings for several external cognitive tests for which a large enough amount of data are present in the database. Whenever available, data provided/published by other test creators is also incorporated into the table. These estimates should be considered preliminary, as the available sample sizes and test connections are still quite limited.

A "test connection" refers to a valid correlation computed between the test in question and another test in the database.

Correlations for the "Nydegger data" are calculated using raw scores for each pair of tests. For standardized assessments, such as the WAIS, correlations are instead calculated between raw scores on the high-range test and standardized IQ scores on the standardized assessment. Based on how other test authors aggregate results from multiple tests into a single correlation value, it appears that they use correlations between standardized scores at least in some cases.

The data come mainly from authenticated candidates whose previous test scores are known and publicly available lists.

Clicking on a correlation coefficient provides access to the corresponding detailed report, containing either the exhaustive list of individual correlations available in the database or the report supplied by the respective test creator.

This page will be updated regularly as additional data become available.
